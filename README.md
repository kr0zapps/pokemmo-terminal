# Rotom-Phone // Operations Terminal v3.0

> All-in-one companion web tool for MMO trainers. Zero login required, 100% offline/local storage enabled, and cross-device synchronization.

Live Web App: **[https://rotom-terminal.vercel.app](https://rotom-terminal.vercel.app)**  
Support the project: **[https://buymeacoffee.com/kr0za](https://buymeacoffee.com/kr0za)**

---

## Key Modules

- **Gym Rerun Terminal**: Track 40 gym leaders across all 5 regions (Kanto, Johto, Hoenn, Sinnoh, Unova) with an interactive 18-hour cooldown tracker and 1h Amulet Coin stopwatch.
- **Berry Farming**: Full garden bed simulation with Wailmer Pail moisture mechanics, phase progression, and harvest alerts.
- **GTL Calculator**: Economic simulator to compare raw berry sales vs. crushing and selling surplus seeds.
- **Seed Crusher (Extracción)**: Audit batch expenses against actual drop rates and GTL market value to calculate exact net profit and ROI.
- **Pokédex Encounter Radar**: Live wild encounter directory synchronized with the in-game day/night/morning clock and season cycles.
- **Breeding Lab**: Step-by-step genetic tree generator for 2x31 through 6x31 projects with exact Power item costs and gender selection fee calculations.

---

## Safety & Security

- **No login required**: Works out of the box in Guest Mode using browser LocalStorage.
- **Non-intrusive**: Operates strictly as an external web companion with zero memory reading or client modifications.
- **Never enter your game credentials**: If creating an optional cross-device account, use a unique password distinct from your actual game account.
